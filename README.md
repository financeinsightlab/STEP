## 🌍 About the Project

**STEP (Sustainable Technology for Energy from Pressure)** is an innovative engineering concept by **Team Stride Green** that proposes harvesting kinetic energy from human footsteps using piezoelectric floor tiles installed in high-footfall public transit hubs like metro stations, airports, and urban walkways.

The project envisions a decentralized micro-energy harvesting system that transforms mechanical pressure from millions of daily footsteps into usable electrical power — supporting ambient LED lighting, passenger information displays, emergency chargers, and IoT sensor networks.

## 🔬 How STEP Works

```
Footstep → Mechanical Pressure → Piezoelectric Conversion → AC Rectification → Supercapacitor Storage → Low-Power Microgrid
```

1. **Capture** — Pedestrians step onto tile, applying downward compressive force
2. **Convert** — Piezoelectric transducers (PZT/PVDF) convert stress into voltage spikes
3. **Condition** — Rectifier circuits turn variable AC pulses into stable DC
4. **Store** — Supercapacitors rapidly absorb charge with high-cycle lifespan
5. **Monitor** — IoT microcontrollers log footfall density and charge rate
6. **Utilize** — Powers ambient LED lighting, sensor arrays, or display signage

## 🚀 Getting Started

This is a static single-page website. To run it locally:

```bash

# Open in browser

```

No build step or dependencies required — just open `index.html` in any modern browser.
